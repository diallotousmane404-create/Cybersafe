# CyberSûr USAZ

**Slogan :** « Comprendre les cyberattaques pour mieux se protéger. »

Plateforme éducative **100 % front-end** (HTML5, CSS3, JavaScript Vanilla) destinée
aux étudiants de l'USAZ. Le site sensibilise aux principaux types de cyberattaques
et enseigne les bons réflexes défensifs.

> ⚠️ **Contenu strictement éducatif et défensif.**
> Aucun outil d'attaque, aucun code malveillant, aucune fausse page de connexion
> fonctionnelle. Les exemples sont fictifs et visent uniquement l'apprentissage.

---

## 🚀 Installation

Aucune dépendance, aucun backend.

1. Téléchargez ou clonez le dossier `cybersur-usaz/`.
2. Ouvrez `index.html` dans un navigateur moderne (Chrome, Firefox, Edge, Safari).
3. C'est tout ✨

Pour un rendu optimal avec `localStorage` et les scripts, vous pouvez servir le
dossier avec un petit serveur local :

# Python 3
python -m http.server 8000

# ou Node.js (npx)
